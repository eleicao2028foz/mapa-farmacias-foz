# Mapa das farmácias de Foz do Iguaçu

Mapa interativo das 4 lojas FARMAIS e das farmácias concorrentes em Foz do Iguaçu.

**Site:** https://eleicao2028foz.github.io/mapa-farmacias-foz/

Atalho para uma loja (ex.: República Argentina):

https://eleicao2028foz.github.io/mapa-farmacias-foz/?loja=farmais-republica-argentina

Outros atalhos: `?loja=farmais-muffato-jk`, `?loja=farmais-consalter`, `?loja=farmais-jules-rimet`. Depois de abrir uma loja, use `&raio=promo` ou `&raio=farmacias` para já ligar “Promoções próximo a mim” ou “Farmácias próximas a mim”.

Este repositório é só o mapa das farmácias. Não altera o site da campanha (`corrida-camara-foz-2028`).
